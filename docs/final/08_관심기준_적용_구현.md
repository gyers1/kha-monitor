# 관심 기준 적용 — 구현 내역 v1

> 협회 공통 관심 기준(B 점수제)을 앱에 연동하고, 직원용 새 화면(오늘의 핵심)을 추가한 변경 기록.
> 기준 설계 근거: `docs/관심기준_초안.md` (검증본 v5)

## 무엇이 바뀌었나

직원이 앱을 열면 이제 **「오늘의 핵심」 + 「그 밖의 오늘 소식」** 구조의 단순 화면(`today.html`)이 먼저 뜬다. 협회 공통 기준으로 점수를 매겨 핵심만 위로 올리고, 나머지는 분야별로 접어 보존한다. 크롤링 주기·사이트 추가·설정 등 관리 기능은 화면에서 사라지고, **관리자만 단축키 `Ctrl+Shift+A`로 기존 전체 대시보드(`/admin`)에 진입**한다.

## 변경 파일

| 파일 | 내용 |
|---|---|
| `config/relevance.json` | 관심 기준 설정값(출처 가중치, 분야, 키워드 핵심/보조/제외, 임계값 5). 관리자는 이 파일만 고치면 됨 |
| `application/relevance.py` | 점수 엔진 `RelevanceScorer` + `get_scorer()`. relevance.json을 읽어 제목을 점수화 |
| `application/__init__.py` | `get_scorer` 등 export 추가 |
| `presentation/api/routes.py` | `ArticleResponse`에 `score / is_core / matched` 추가, `/api/articles`가 점수 포함해 반환 |
| `main.py` | `/`는 직원용 `today.html`(없으면 dashboard 폴백), 기존 대시보드는 `/admin`으로 이동 |
| `presentation/templates/today.html` | 직원용 새 화면(신규) |
| `MonitoringDashboard.spec` | 빌드 datas에 `today.html`, `relevance.json` 추가 |

## 점수 규칙 (요약)

```
총점 = 출처점수(S+3/A+2/B+1) + 분야점수(입법예고·행정규칙+2, 의안정보·전자관보+1)
       + 키워드(핵심+4 / 보조+2) + 상임위통과((대안)·위원장) +1
       − 제외어 −3 − 비수도권지역(법령신호 없음) −2
전제: 핵심·보조 키워드가 하나도 없으면 핵심 불가(−99)
임계값 5점 이상 → is_core=true → 「오늘의 핵심」
```

과거 24,150건 검증: 핵심 약 7.5%(하루 약 8건), 노이즈 약 92% 감소.

## 동작 방식 / 폴백

- `relevance.json`이 없으면 점수 엔진은 빈 기준으로 동작(모두 비핵심) → 앱은 깨지지 않음.
- `today.html`이 없으면 `/`는 기존 `dashboard.html`로 폴백.
- 기존 API·크롤링·알림 로직은 그대로. 점수는 조회 시점에 계산(저장 안 함)이라 기준만 바꾸면 즉시 반영.

## 검증

- `application/relevance.py`는 history.db로 단위검증 완료(하천정비=비핵심, 주택법(대안)=핵심+가중, 무주제=−99, 지역감점 적용).
- ※ 작성 환경의 파일 동기화 문제로 일부 자동 문법검사는 호스트 파일 직접 확인으로 대체함.

## 운영 메모

- 관리자는 새 이슈 키워드를 `relevance.json`의 `core_keywords`에 추가(분기 1회 점검 권장).
- 잔여 미세 오탐(예: 일부 기관 운영 소식)은 `negative_keywords`로 보강.
- 향후 LLM 보강은 중앙 1대(관리자 PC/Ollama)에서 제목 점수를 보정하는 단계로 별도 추가 가능.

## v1.1 — 직원 화면 개선 (전문가형 + 카테고리화 + 중복 병합)

피드백 반영 사항:

- **전문가(로펌) 톤 재디자인**: 카드 나열식 → 문서형(분야별 묶음, 세리프 제호, 절제된 남색 액센트, 헤어라인 구분). 캐주얼 인사·이모지 제거.
- **핵심을 분야별로 분류**: 「오늘의 핵심」을 입법예고·행정규칙·의안정보·보도자료·전자관보 순 소제목으로 묶어 표시(단순 나열 해소).
- **중복 게재 병합(클러스터링)**: 같은 내용이 여러 출처에 뜬 경우 한 건으로 묶고 `N곳 게재 + 출처 목록`으로 표기. 대표는 가장 권위 있는 분야(입법예고 등)로, 관보 중복은 자동 흡수. 예) `주택법 시행령 일부개정령안`이 국토부 입법예고·법제처 입법예고·관보 → 1건(3곳). 검증: 2026-06-29 기준 138건 → 112건으로 압축.
  - 정규화 로직: 관보 `제NN호(실내용)`는 괄호 안을 본문으로 추출, 문서종류 접미어(입법예고/일부개정령안/고시 등)·괄호·번호 제거 후 키 비교(`today.html`의 `normKey`).
- **그 밖의 소식 — 부처별 2차 분류**: 분야를 펼치면 그 안을 부처(출처)별로 다시 묶어 표시(예: 보도자료 → 서울특별시·행안부·환경부·재경부·국토부). 출처가 한 곳뿐이면 부처 소제목은 생략. (※ 전자관보는 단일 출처 '대한민국 관보'라 부처로 안 갈림 — 추후 관보 제목 안의 발령기관 파싱으로 세분화 가능)
- **갱신 정보 표시**: 상단 우측·하단에 `최종 수집 HH:MM · 자동 수집 N분 간격`(간격은 `/api/sites`의 interval에서 산출).
- **관리자→직원 복귀**: 관리자 대시보드 좌측 사이드바에 ‹ 버튼(`직원 화면으로 돌아가기`, `/`로 이동) 추가.
- **인증 게이트 옵션화**: 구글 Apps Script 인증은 `auth_script_url`+`auth_token`이 설정된 경우에만 강제. 미설정 시(테스트 등) 개방. (`main.py` auth_guard)

변경 파일(추가): `presentation/templates/today.html`(전면 개편), `presentation/templates/dashboard.html`(복귀 버튼), `main.py`(auth_guard 옵션화).

## v1.3 — 일일 동향보고 초안 + 새 소식 추적 + 아침 알림

변경 파일(추가): `presentation/templates/today.html`(동향보고 모달·NEW 추적), `main.py`(morning_briefing 잡 + get_scorer import).

## v1.5 — 요약 추출 개선 + 출처별 진단 도구

추출기 개선(`_fetch_summary`):
- **한글 인코딩 자동 감지**: `resp.text` → `resp.content`(바이트)로 파싱해 EUC-KR/UTF-8 혼재 정부 사이트의 깨짐 방지.
- **관보(PDF) 건너뛰기**: `gwanbo.go.kr`·`ezpdf`·`.pdf`는 본문이 PDF라 추출 생략(제목으로 충분).
- **본문 선택자 대폭 확장**(`_SUMMARY_SELECTORS`, 25종+)으로 정부 게시판 본문 적중률 향상. `verify=False`·`Accept-Language: ko`로 접근성 보완.

출처별 진단 도구:
- `GET /api/summary-check`: 활성 사이트별 최신 기사 1건으로 추출을 병렬 시도해 `○성공/△약함/✗실패/–없음` + 글자수 + 미리보기 반환.
- `/summary-check` 페이지(`summary_check.html`) + 관리자 사이드바 돋보기 버튼. 관리자 PC(정부 사이트 접속 가능)에서 한 번 돌리면 어디가 되고 안 되는지 한눈에 확인 → 안 되는 곳만 선택자 보강.
- ※ 작성 환경(샌드박스)은 정부 사이트 직접 접속이 막혀 있어 실제 추출 검증은 사용자 PC에서 수행해야 함.

변경 파일(추가): `routes.py`(/api/summary-check, 추출 개선), `main.py`(/summary-check), `summary_check.html`(신규), `dashboard.html`(점검 버튼), `MonitoringDashboard.spec`.

## v1.7 — 직원 화면 = 기존 대시보드(직원 모드) + 현안

사용자 피드백: 기존 관리자 대시보드의 렌더링이 더 우아·깔끔. → **별도 today.html 폐기하고, 직원 화면도 실제 `dashboard.html`을 그대로 사용.**

- `main.py`: `/` → `dashboard.html`(직원 모드), `/admin` → `dashboard.html`(전체). 동일 파일을 경로로 구분.
- `dashboard.html`(기존 6000줄 **무수정**, 끝에 `<style>+<script>` append만):
  - `location.pathname==='/'`면 `body.employee-mode` → 사이드바에서 dashboard 외 nav(설정·요약점검·복귀) 숨김, `기준선 재설정` 숨김. 직원 모드에서 `Ctrl+Shift+A` → `/admin`.
  - `#dashboardPage` 최상단에 **「오늘의 협회 관련 현안」** 섹션 주입: `allArticles`(이미 `is_core/score/matched` 포함)에서 핵심만 클러스터(중복 병합)해 **주제(키워드) 태그를 앞세워** 표시. 카드 클릭은 기존 `openPreview` 재사용. 카테고리 필터 시 자동 숨김. `MutationObserver`로 데이터 갱신 시 재렌더.
